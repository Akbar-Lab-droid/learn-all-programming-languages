## How to Use This Repo

1. **Read the Foundation Modules first** — how computers work, how to learn coding, Git, and algorithms. They apply to every language.
2. **Pick ONE first language** from the roadmap below. Don't learn 3 languages at once in the beginning.
3. **Follow its path step by step** — basics → intermediate → projects. One free course per stage is enough.
4. **Build a project at every stage** — code you don't practice disappears. Every language has a list of practice projects.
5. **Only then add a second language** — after you can build one real project with the first. Your second language will be much easier: 80% of the concepts are the same, only the syntax changes.

Every language comes with a **complete mini-course** in the [`guides/`](guides/) folder (15+ sections: syntax, strings, files, errors, a mini-project, exercises, interview questions) and **172 real code examples** in the [`examples/`](examples/) folder — 10 real programs per language, with comments in English.

## Which Language First? (Roadmap)

| Your goal | Start with |
| --- | --- |
| Never coded before | **Python** — easiest to read, most tutorials |
| Want to build websites | **HTML & CSS** → **JavaScript** → **TypeScript** |
| Want to build Android apps | **Kotlin** (or Java) |
| Want to build iOS apps | **Swift** |
| Want to work in data / AI | **Python** → **SQL** → **R** |
| Want to work in games | **C#** (Unity) or **C++** (Unreal) |
| Want to work in systems / fast backends | **Go** or **Rust** |
| Studying Computer Science | **C** → **Java** → **Python** (the order most universities use) |
| Want to freelance websites fast | **PHP** + JavaScript |

Rule of thumb: **your first language doesn't matter — finishing one project does.** The second language takes 30–50% of the time the first one took.

## Foundation Modules — Before You Pick a Language

### How Computers Work (1 week)

- **CS50 Harvard** — the best free intro to computer science in the world: https://cs50.harvard.edu
- **Khan Academy Computing** — computer & internet basics: https://www.khanacademy.org/computing

### How to Learn Coding the Right Way

- **Don't just watch tutorials** — type every line of code yourself, change it, break it, fix it.
- **The 20-minute rule** — if you're stuck for more than 20 minutes, search Google/Stack Overflow. Don't sit in silence.
- **Learning How to Learn** — free course on how to learn: https://www.coursera.org/learn/learning-how-to-learn
- **Write down your errors** — the same error should never cost you twice.

### Git & GitHub (required for every language)

- **GitHub Skills** — interactive free Git lessons: https://skills.github.com
- **Pro Git Book** — free book: https://git-scm.com/book/en/v2
- Must-know commands: `clone`, `add`, `commit`, `push`, `pull`, `branch`, `merge`.

### Algorithms & Data Structures (required for every language)

- **Khan Academy Algorithms** — intro to algorithms: https://www.khanacademy.org/computing/computer-science/algorithms
- **freeCodeCamp** — algorithms & data structures curriculum: https://www.freecodecamp.org/learn/
- Must-know topics: arrays, strings, linked lists, stacks, queues, hash maps, sorting, searching, Big-O.

**Difficulty:** ⭐ Easy — the best first language for beginners.

## FAQ

**How many languages should I master?**
One first, until you can build a real project with it. After that, a second language takes 30–50% of the time the first one took. Senior programmers usually know 3–5 languages, but go deep in 1–2.

**Which language has the most job openings?**
JavaScript, Python, Java, and PHP — in that order, for web and backend. For data/AI: Python and SQL.

**Do I need a Computer Science degree to become a programmer?**
No. Most skills in this repo can be learned on your own through the free courses above. A degree helps at the start; a portfolio decides.

**I'm stuck on one topic, what do I do?**
That's normal. Search Stack Overflow (https://stackoverflow.com), ask in the freeCodeCamp forum or a community Discord, and take a break — the solution often appears after a pause.

**How long until I can get a job?**
With 2–3 hours of practice per day: 6–12 months until an internship/junior role, depending on the language and consistency. A portfolio of 3 real projects beats 10 certificates.
