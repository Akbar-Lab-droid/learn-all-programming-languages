# 12-Week Roadmap — From Zero to Job-Ready

A week-by-week plan using this repo. Spend 2–3 hours a day. Pick ONE first language (Python is recommended if you are unsure) and follow the plan.

## Weeks 1–2: Foundations
- [ ] How computers work — CS50, week 0–1: https://cs50.harvard.edu
- [ ] Git & GitHub — create an account, learn `clone`, `add`, `commit`, `push`: https://skills.github.com
- [ ] How to learn — "Learning How to Learn": https://www.coursera.org/learn/learning-how-to-learn
- [ ] Algorithms basics — arrays, Big-O: https://www.khanacademy.org/computing/computer-science/algorithms

**Done when:** you can create a repo, commit code, and push it to GitHub.

## Weeks 3–4: Your First Language (Basics)
- [ ] Read the complete guide for your language in [`guides/`](guides/)
- [ ] Finish the "Basics" sections: variables, types, conditionals, loops, functions
- [ ] Run every example in [`examples/<your-language>/`](examples/)
- [ ] Do the 3 practice exercises at the end of your guide

**Done when:** you can write a 50-line program from scratch without copying.

## Weeks 5–6: Your First Language (Intermediate)
- [ ] Data structures, OOP, error handling, file I/O
- [ ] Start one free course for your language (see its section in the README)
- [ ] Build project #1: a CLI tool (calculator, to-do manager, or file organizer)

**Done when:** project #1 is on your GitHub with a README.

## Weeks 7–8: Build & Practice
- [ ] Build project #2: something with data (CSV analysis, a small web app, or a bot)
- [ ] Solve 20 problems on LeetCode or HackerRank in your language
- [ ] Learn SQL basics — every app needs a database

**Done when:** you have 2 projects on GitHub and 20 solved problems.

## Weeks 9–10: Second Language + Specialization
- [ ] Pick your second language from the roadmap in the README (e.g. JavaScript if you started with Python)
- [ ] Read its guide in [`guides/`](guides/) — it will feel 2× faster than the first
- [ ] Choose a specialization: web (JavaScript/TypeScript), data/AI (Python/SQL), mobile (Kotlin/Swift/Flutter), or systems (C++/Go/Rust)
- [ ] Build project #3 in your specialization

**Done when:** project #3 is live (a deployed website, a working app, or a data dashboard).

## Weeks 11–12: Portfolio & Job Prep
- [ ] Polish your 3 projects: good READMEs, screenshots, live demos
- [ ] Write your CV: skills, projects, GitHub link at the top
- [ ] Practice interviews: 30 LeetCode easy/medium problems
- [ ] Apply for internships and junior roles — 5 applications a week

**Done when:** your GitHub profile shows 3 solid projects and you are applying for jobs.

---

## Rules That Make This Work
1. **Code every day, even 30 minutes.** Consistency beats weekend marathons.
2. **Type the code yourself.** Copy-paste teaches nothing.
3. **One language at a time** until you finish a project with it.
4. **Stuck for 20+ minutes?** Search, ask, then move on — don't freeze.
5. **Ship projects, not certificates.** Employers read your GitHub, not your course list.

Good luck — and star the repo if the plan helps you. ⭐
