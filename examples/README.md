# Code Examples — Learn All Programming Languages

Every language has **2 real code examples** you can run right away. Start with `hello` (your first program), then one practical example (calculator / FizzBuzz / analysis).

| Language | Files | How to run |
| --- | --- | --- |
| Python | `python/hello.py`, `python/calculator.py` | `python3 python/hello.py` |
| JavaScript | `javascript/hello.js`, `javascript/fizzbuzz.js` | `node javascript/hello.js` |
| TypeScript | `typescript/hello.ts`, `typescript/calculator.ts` | `npx tsc` then `node` the compiled output, or Node 22+ directly |
| HTML & CSS | `html-css/hello.html`, `html-css/style.css` | Open `hello.html` in a browser |
| SQL | `sql/hello.sql`, `sql/analysis.sql` | Run in SQLite / MySQL / PostgreSQL |
| Java | `java/HelloWorld.java`, `java/Calculator.java` | `javac HelloWorld.java && java HelloWorld` |
| C | `c/hello.c`, `c/calculator.c` | `gcc hello.c -o hello && ./hello` |
| C++ | `cpp/hello.cpp`, `cpp/fizzbuzz.cpp` | `g++ hello.cpp -o hello && ./hello` |
| C# | `csharp/Hello.cs`, `csharp/Calculator.cs` | `dotnet run` (create a project first) |
| Go | `go/hello.go`, `go/fizzbuzz.go` | `go run hello.go` |
| Rust | `rust/hello.rs`, `rust/fizzbuzz.rs` | `rustc hello.rs && ./hello` |
| PHP | `php/hello.php`, `php/calculator.php` | `php hello.php` |
| Ruby | `ruby/hello.rb`, `ruby/fizzbuzz.rb` | `ruby hello.rb` |
| Swift | `swift/hello.swift`, `swift/fizzbuzz.swift` | `swift hello.swift` |
| Kotlin | `kotlin/Hello.kt`, `kotlin/FizzBuzz.kt` | `kotlinc Hello.kt -include-runtime -d hello.jar && java -jar hello.jar` |
| Dart | `dart/hello.dart`, `dart/fizzbuzz.dart` | `dart hello.dart` |
| R | `r/hello.R`, `r/analysis.R` | `Rscript hello.R` |
| Shell/Bash | `shell/hello.sh`, `shell/backup.sh` | `bash shell/hello.sh` |

All examples are written with comments in English and have been checked for correctness.
